# Changelog

## 1.0.0

Initial release of EMCICalc Desktop Edition.

- Desktop and Calculator modes with independent appearance and window settings.
- Exact and approximate calculation, symbolic mathematics, units and currency.
- Graph, matrix, statistics and Finance workspaces; bounded Steps explanations.
- Natural/linear input, keyboard controls, history, registers and workspace exchange.
- Nine interface languages, accessibility labels and bundled CJK fallback fonts.
- Native Windows and GNU/Linux build recipes, portable packaging and Debian layout.
- Automated source/regression checks and manual source archives with checksums.

Build instructions and platform validation requirements are linked from the README.
